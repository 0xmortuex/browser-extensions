GitHub Pulse

The bar under each repository shows its latest workflow runs, deployment and release from GitHub's public API. Nothing here is needed for that.

Cloudflare Workers (optional)

To also see when a repo's Worker was last deployed, give a read-only API token: Cloudflare dashboard › My Profile › API Tokens › Create Token › Workers Scripts: Read. A repo is matched to the Worker with the same name, with or without -worker. The token stays in this browser and is only sent to api.cloudflare.com.
